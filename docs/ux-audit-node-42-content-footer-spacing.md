# 手機內容區與頁尾留白

本輪接續全站高度複驗，處理主要內容與頁尾，而非再縮小大標題。

- 手機頁尾原本底部預留 90px 加安全區，而頁面外框已預留底部導覽高度。本輪改為上下 20px／16px，縮短品牌介紹間距，社群連結仍保留 44px 點按高度。桌面樣式保留。
- 新手頁詳細準備與後續行動卡片改為 10px 垂直間距、6px 內容間距，維持完整文字、章節及連結。
