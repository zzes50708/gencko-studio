## 最終行為

- 僅 767px 以下移除頂部導覽與 64px 預留空間；底部統一首頁、選購、知識、工具、更多。
- 更多包含會員、亮／暗模式、可安裝時的 App 安裝及所有品牌頁。選單切換頁面或擴大至電腦寬度時自動關閉，恢復背景捲動。
- 飼養與健康評估進度列固定於頂部安全區，不再隨頂部導覽隱藏狀態向上偏移。文章閱讀進度、飼養指南錨點、比較詢問按鈕及底部操作區同步調整。
- Hero Lab 手機保留底部導覽，移除獨立頂部首頁按鈕；固定展示區保留底部導覽空間。電腦維持原有展示模式。

- 手機選項字級縮減；數量彈出清單以三欄／六欄完整顯示，包含 0 與 10–80cm 共 72 個收納高度，不需要清單捲動。桌面保留原生選單。
