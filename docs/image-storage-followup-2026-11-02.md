# 圖片與收藏失敗情境補查

本輪延續全站回歸排查，使用隔離圖片及瀏覽器儲存失敗重現問題；沒有修改正式資料。

## 已重現的問題

- 購物卡片：高解析候選圖片失敗、400px 原始來源成功時，仍顯示「照片暫時無法載入」。現在先移除候選、載入原尺寸，原尺寸亦失敗才顯示替代內容。
- 個體詳情：相同情境下會隱藏仍可載入的 800px 照片；SSR 掛載補查與原生錯誤事件又可能重複計入同一次失敗。現在依圖片實際載入模式核對事件，避免把舊候選錯誤當成原尺寸失敗；明確重試仍會重新嘗試候選。
- 文章圖片：同樣的重複錯誤事件會提前隱藏原尺寸，補上相同的事件模式核對。
- 個體頁收藏：拒絕寫入 gencko_wishlist 時，操作會觸發「頁面發生錯誤」並中斷內容。現在保留本次瀏覽的收藏狀態。
- 會員頁的個體及院所收藏有相同未處理寫入錯誤，現已一併補上防護，取消收藏不會中斷頁面。

## 驗證方式

- 使用真實 UI，僅將測試個體及圖片回應隔離；指定候選回傳 404、原尺寸回傳可解析圖片。
- 對照舊正式建置，購物、個體照片及個體收藏三個案例先失敗，再驗證修正版。
- 額外對同一候選圖片同步發出兩個錯誤事件，舊建置會隱藏原圖；修正版需繼續載入原圖。
- 拒絕個體及院所收藏的本機寫入，核對商品頁切換收藏、會員頁取消兩種收藏，以及主要內容仍可操作。
- 重跑完整手機／桌機發布回歸與單元測試，並使用嚴格 ESM 模式的正式建置。

## 結果

- 正式模式建置成功；完整桌機／手機發布回歸 70 項通過，單元測試 61 個檔案、367 項通過。
- 原失敗輸入對照：購物與個體頁均重新載入原尺寸照片；拒絕寫入收藏後主要內容仍正常。
- 個體頁、會員個體收藏及會員院所收藏的失敗防護，桌機與手機均有實際點擊驗證。
- 圖片與 API 故障注入停用 Service Worker，避免快取的成功結果掩蓋真正失敗；另重跑整份回歸案例確認此隔離設定。
