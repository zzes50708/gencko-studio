目前沒有進行中的真實競標，因此競標內頁以隔離測試資料檢查；舊周邊內頁確認轉向 /merch。會員登入狀態使用瀏覽器隔離測試資料，未操作真實登入或出價。

## 本輪修改

- 次要導流入口統一為兩欄短列、細分隔線與明確文字，避免各頁自行堆疊大型框線按鈕。介紹、購買、FAQ、健康與準備度評估一併處理。
- 會員頁縮短說明、訪客資訊卡、分類及空狀態間距。
- 故事頁三個入口改為兩欄，避免三顆全寬按鈕占高。
- 種群物種切換、搜尋與列表間距縮減，保留既有圖片展示及搜尋方式。
- 新手流程、章節導覽及知識入口間距縮減。
- 比較頁操作同行排列，空狀態縮短裝飾數字、說明與空白。
- 手機品牌介紹第一幕文字上移，桌面維持原有置中；保留輪播、動畫、滑動與底部導覽。
- 手機錯誤頁由四顆全寬按鈕改成兩欄，減少上方空白。
- 飼養評估離頁時立即取消自動換題計時器，避免等待下一頁載入時覆寫進度。
- 校正樣式順序，確保緊湊規則實際生效，而非被各頁舊間距覆盖。主要導流入口保留 44px 觸控高度。

## 驗證

- 27 個實際路徑於 320、390、1440px 逐頁檢查，共 81 個畫面，未出現橫向溢出。
- 競標測試內頁與舊周邊轉址於 320、390、1440、1920px 檢查。
- 26 個相關功能案例：24 個成功，2 個導流觸控尺寸案例在調整至 44px 後，包含它們的四個介紹／飼養案例全部重跑成功。
- 品牌互動與錯誤恢復九個案例成功；評估離頁計時器修正後三個案例成功。
- 38 個目前修改的 Vue 檔案編譯成功。沒有進行部署。
