# 節點 61：3D 爬櫃完整檢查與補充修正

## 本輪修正

- 工作區改成開啟後才動態載入，載入中有狀態文字，模組下載失敗可重試。配置元件首次載入後保留，不會因視窗開關遺失設定。
- WebGL context 遺失後提供「重新生成模型」，重試保留層數及其他配置。修正 fallback 原先禁止 pointer events，導致重試按鈕可見卻不能觸控的問題。
- 材質下載失敗會移除請求記錄，重新生成時可以再次下載；成功材質仍沿用快取。
- 舊批次著色器等待也檢查更新序號，避免過期工作繼續等待。
- 背景頁停止繪製及相機移動，清除畫質恢復計時器，前景恢復時重新繪製；卸載移除監聽器。
- 層數、盒數及其他數量彈出選單，每格固定 36px，移除隨可用高度拉大的留白，仍依橫向空間增加欄數。
- 收納內高：0 或 10–80cm，每 5cm 一級。桌面數字輸入 step=5，資料正規化亦套用相同級距，避免畫面與匯出不同。
- 溫控器改成鑲嵌式薄面框、深色顯示窗、橘紅溫度數字及三個操作鍵；溫度計保留原樣。照片中的後方機身、接線及紅色固定扣不外露。
