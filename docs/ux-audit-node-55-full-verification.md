## 本次修正

- FAQ 開發環境的樣式網址依 `Accept` 回傳 CSS 或 JavaScript，快取原先未區分兩者。新增 `Vary: Origin, Accept`，避免返回頁面時收到錯誤 MIME。

- 手機爬櫃更新提示避開右上角尺寸資訊；更新時仍可操作選項。
