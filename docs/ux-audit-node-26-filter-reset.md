# 節點 26：搜尋與清除的一致性

## 重現與修正

選購頁搜尋有 250ms 延遲，立即重置時沒有取消計時，舊字串會再次變成有效條件。取消待執行搜尋，另外同步管理即時輸入字串，讓重置能確實清掉尚未提交的文字。

ShopFilters 的基因搜尋是元件本地狀態，手機「清除」原本只清除篩選值，搜尋文字仍留下。清除草稿與全部重置時更新元件 key，同步清掉本地搜尋與分類展開狀態，保留既有草稿提交流程。
