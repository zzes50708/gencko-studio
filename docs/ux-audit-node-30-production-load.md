# 節點 30：正式建置與首次載入

## 建置

使用 output/ux-node30-build.mjs，buildDir 與 Nitro output 都隔離，node-server 預覽只綁定本機 3040。初版及修正版兩次正式建置均 exit 0。原開發服務保留，未部署或寫入遠端。

## 修正

工作區原本在啟用 3D 時同時載入清水模、石紋共六張模型貼圖。現在只載入所選紋理貼皮；純色不載入，切換後載入來源保留，每套只請求一次。色票本身仍會顯示既有預覽圖片。

## 量測與限制

Chromium 手機視窗，本機正式預覽，獨立瀏覽器 context，Service Worker 停用。每版一次樣本，未做網路或 CPU 限速。

| 正式預覽                       |          修改前 |          修改後 |
| ------------------------------ | --------------: | --------------: |
| 本機來源資源 transferSize 總和 | 8,851,227 bytes | 5,130,010 bytes |
| 模型畫布出現且 aria-busy 結束  |        9,304 ms |       11,575 ms |
| 最大長任務                     |        7,483 ms |        7,747 ms |
| 未捕捉頁面錯誤                 |               0 |               0 |

傳輸量減少約 42%，但此樣本沒有證明完成時間改善。保留約 7.7 秒長任務需要繼續定位；不能直接推論為使用者手機上的 GPU 耗時，也不能以 headless 本機結果宣稱實機效能。

修改前開發版完成時間 18,119 ms，修改後 15,143 ms；開發資料受編譯、快取、負載影響，只供區分環境，不當作正式速度指標。

原始資料 output/ux-node30-load-before.json、output/ux-node30-load-profile.json，腳本 output/ux-node30-load-profile.mjs。兩份建置紀錄 output/ux-node30-build.log、output/ux-node30-final-build.log。正式手機畫面 output/ux-node30-production-mobile.png 已檢視。

## 驗證

貼圖選取／切換／不重複下載測試 1 項通過；資源釋放與手機旋轉、縮放、持續修改／最後配置生效測試 3 項通過。首次貼圖測試誤將預設純色當成清水模，修正先選擇清水模後再驗證。

本機預覽在驗證後停止。尚未部署。下一節點以瀏覽器 trace 定位首次渲染長任務，保留手機可旋轉、縮放與桌面同材質的規格。
