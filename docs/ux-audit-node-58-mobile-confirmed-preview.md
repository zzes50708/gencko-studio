# 節點 58：手機滿版配置與確認生成

## 使用者需求

手機改成在目前頁面開啟滿版 3D 客製模擬系統，設定尺寸後確認才生成模型；場景背景更白。保留前一節點的材質程式重用與 LED 擴散調整。

## 實作

- 手機入口開啟原生 dialog，使用 100dvh 並保留安全區，第一階段僅顯示配置表單，不建立模型或 WebGL 畫布。
- 「確認生成模型」建立模型；「調整配置」返回表單，修改合併到再次確認後更新。編輯期間保留並暫停既有渲染器，避免重新編譯材質。
- 關閉視窗釋放 3D 資源，保留配置；再次開啟仍需確認。瀏覽器返回先關閉視窗，還原入口焦點與背景捲動。
- 巢狀選單關閉後仍維持外層視窗的捲動鎖定。
- 電腦維持頁內模型及即時更新，背景同步變亮；手機增加可用視距，避免滿版窄螢幕標註被 OrbitControls 的距離限制裁切。
- 修復關閉時過早清空 model 導致 Tres 子元件讀取 null.target 的錯誤：先卸載畫布，再清空與釋放模型。
- LED 光暈高度由 1.2 增為 1.6、垂直衰減略放寬，面光源高度由 0.8 增為 1.1；保持原光源數量及強度。

- 電腦 1440px：維持頁內模型及直接修改層數。
- 手機原生觸控旋轉與雙指縮放；更新等待期間仍能返回配置並提交最後選擇，保留旋轉視角。
