# 競標與管理持續複驗第七輪（2026-10-20）

## 實際重現與修正

1. LINE 聯絡狀態為 null 或缺少 required／ready／restricted 時，沒有明確錯誤，部分缺欄位物件會被當成可出價狀態。現在要求三個布林欄位完整；異常回應撤下舊狀態、通知父層未通過驗證並提供重試。資料庫出價權限判斷仍保留，這是前端防呆，不代表重現了繞過後端的出價。
2. 單場得標回應為空物件、其他場次或字串金額時，仍可能顯示成交或複製入口。新增共用結果檢查，核對場次、已知狀態、整數金額與日期；合法 null 仍代表無本人得標結果。
3. 會員得標列表只檢查陣列，沒有核對每筆。現在逐筆驗證後才呈現，任一壞資料不會顯示部分可信、部分失真的紀錄。合法空陣列仍顯示沒有得標待辦。
4. 領標訊息過了 15 分鐘仍留在畫面。改依回應中的有效期與伺服器校時設定單次計時，到期清除舊文字及 LINE 連結，提示重新產生；返回分頁或恢復上網時補查。切換結果、帳號及離頁會清理計時器。
5. 產生領標訊息的回應原先只檢查 message 有值。現在要求純文字訊息、有效且未過期的有效期，以及與目前得標結果一致的成交金額。壞資料與舊碼不供複製。剪貼簿延遲完成時也不能把已過期提示覆寫成「已複製」。

LINE 異常、得標單場／列表壞資料、領標到期案例均先跑出失敗，再修改並重跑通過。另以空物件、不同場次、字串金額、未知狀態、錯誤日期、非文字訊息、錯誤金額與已過期回應驗證防呆。領標到期以瀏覽器時鐘快轉驗證，不改正式資料庫時間。

## 回歸範圍

包含即時價格及延長、舊回應、密集事件、斷線重試、登入過期、換帳號、重複點擊、預約上架、交易占用、管理權限、千筆出價、核帳、延期、限制範圍、會員付款、領標隔離與 48 小時保留。測試使用隔離瀏覽器假資料，未建立真實出價或傳送 LINE 訊息。
