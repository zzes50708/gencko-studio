- 3D 更新測試包含初次 WebGL 載入與多次更新，原總時限 30 秒不足；保留所有原斷言，各階段等待不變，將總時限改成 60 秒。重跑更新情境 31.1 秒通過。

- 首頁文章錯誤測試的人工資料遭真實請求覆蓋；固定初始文章回應並等待資料載入完成，才注入失敗與重試資料。
- 手機導覽測試在 SSR 頁面按鈕尚未完成初始化前觸發操作；等待元件完成初始化後再操作，保留背景隔離、返回與捲動解鎖斷言。
