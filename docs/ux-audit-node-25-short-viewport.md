# 節點 25：手機低可視高度

## 範圍與結果

Chromium 觸控模式，740×320 橫向視窗逐一打開爬櫃可使用的選單，確認面板上下界位於畫面內、最後一個選項可見、關閉可點按。沒有需要修改的產品問題。

390×320 低高度視窗打開工具導覽，確認關閉仍在可視範圍，點選基因計算機能導頁且解除背景捲動鎖定。兩個觸控測試通過（18 秒）。

初次測試逾時是點擊停用的底部收納選項；修正測試跳過停用項目後，滑鼠模式與觸控模式均通過。此次未變更產品介面，未部署。

## 限制

低高度模擬不等同 iOS／Android 真實軟鍵盤，也不涵蓋 visualViewport 位移。不能據此宣稱實機鍵盤已全部驗證。一般導覽內容允許捲動；爬櫃選單保留使用者指定完整顯示的規格。
