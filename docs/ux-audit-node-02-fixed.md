## 驗收界線

### 手機資訊密度追加修正

依使用者回饋，手機卡片僅保留照片、品系與價格；收藏／比較改為價格右側的具名圖示按鈕。ID、性別、出生年與完整基因移至原生「基本資訊」展開區；桌面維持完整資訊。390px 實際庫存畫面卡片約 308px 高，無水平溢出；截圖：output/ux-node2-mobile-compact.png。篩選、比較、返回等六項測試重新驗證，新增折疊資訊觸控驗證。本次預覽：http://localhost:3002/shop，尚未部署。

瀏覽器為 Chromium 與原生觸控事件模擬；未以實體 iPhone／Android、Safari 或螢幕閱讀器驗證。沒有發送 LINE 訊息。尚未開始後續節點，也未修改既有其他頁面的五項檢查落差。
