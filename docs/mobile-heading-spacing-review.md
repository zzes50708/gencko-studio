# 手機版標題與留白統一

使用者回饋：選購頁首屏留白仍太多，種群展示的標題位置不同，不應依賴使用者逐頁比對。

## 修正

- 共用手機標題字級 24px、行高 1.12，取消各頁殘留的展示高度與左側標題裝飾留白。
- 外層容器移除重複的 15px 頂部 padding，頁面統一保留 8px。
- 英文導引列固定一列，過長的輔助標語以省略方式顯示，完整文字仍在 DOM；不再把其他頁的標題推往下一行。
- 標題文字容器使用一般文字流，取消網格列間距；種群、首頁、爬櫃等不再額外保留空列。
- 說明與提醒文字保留緊湊的閱讀間距，選購提醒到篩選的 margin／padding 不再重複堆疊。
- 文章與身分證的內層標題 padding 亦縮減。
- 所有修改均在 max-width:767px 中，桌面排版不變。

## 覆蓋與驗證

19 個內容入口：選購、種群、競標、爬櫃、計算機、基因圖鑑、文章列表、守宮介紹、飼養指南、FAQ、新手入門、健康評估、醫院查詢、購買流程、品牌介紹、故事、會員、比較、首頁。

以 320px 與 390px 逐頁瀏覽，確認上述頁面標題起點距頂部 50px、字級 24px、無水平溢出。長標題自然換行，不強制裁切或硬塞相同高度。

飼養前評估亦检查：固定進度列仍滿版，標題保留工具列所需的實際高度，未被遮擋。

另查看個體詳情、電子身分證、基因詳情、文章詳情；這些標題前有照片、返回或文件內容，因此保留順序與自然位置，僅統一字級及縮減空白。競標詳情檢查無資料狀態，舊商品詳情檢查轉址。關於我們、根路徑與 Hero Lab 為既有全螢幕場景，不強制搬動場景內的文字。
