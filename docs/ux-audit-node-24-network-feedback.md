# 節點 24：離線與長時間等待

## 問題與修正

斷網時全站沒有明確提示；換頁請求等待很久時，只有頂端載入線及輔助閱讀文字。

使用 VueUse useOnline 偵測瀏覽器連線狀態，離線時在導覽下方顯示精簡提示。恢復連線即移除，不自動重送操作或重新整理頁面。掛載後才顯示，避免伺服器輸出與瀏覽器狀態造成閃爍。

換頁載入超過 8 秒時，原本的輔助閱讀狀態改為可見說明。載入結束或下一次載入時清除計時與提示；卸載時清除計時。提示使用一般文件流，不覆蓋導覽選單與觸控操作。

## 驗證

新增兩個測試先確認缺少提示而失敗，再修正。Chromium 模擬離線／恢復與延遲 API，確認既有內容仍可見、手機沒有橫向溢出、連線恢復提示消失、慢速載入完成後提示清除。

與既有載入線、aria-busy、返回測試合計 3 項通過；app.vue 腳本與模板編譯通過。未部署、未正式建置。

連線提示反映瀏覽器 online 狀態，不代表後端服務一定可用；HTTP 錯誤仍使用各頁的重試流程。本節點不變更 Supabase 重試與交易行為。
