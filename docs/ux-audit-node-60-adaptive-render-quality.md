# 節點 60：操作流暢與停止後高清

## 改動

- 自動畫質分成操作與靜止狀態：旋轉、縮放、相機按鍵動畫與盒體抽拉時降低渲染像素；結束約 200ms 後恢復高清。畫質切換不修改材質、盒壁幾何或 LED 數量。
- 裝置能力使用核心數及可取得的記憶體提示；缺少提示仍可使用。手機靜止倍率最高 1.75、一般桌面最高 2；低能力裝置上限 1.25。桌面原生 1 倍螢幕可使用輕度超採樣。
- 總渲染像素預算：一般手機 150 萬、一般桌面 240 萬、低能力裝置 90 萬；超寬螢幕仍受預算限制。
- 操作幀時間採平滑取樣，每 12 個有效幀有界調整倍率；排除長待機間隔，不會每一幀反覆切換畫質。
- 透明折射解析度：手機操作 0.55、桌面操作 0.75，停止恢復 1；原材質透明度與板厚保留。
- 陰影尺寸依能力固定在 512 / 1024 / 2048。停用每幀自動重畫陰影，只在模型、光源或抽拉變動時標記更新；旋轉相機沿用陰影。
- 貼圖斜角取樣提高到裝置支援的最高 8 倍；使用前節點的共用盒體細節幾何與材質程式快取。
- 清理畫質恢復計時器及控制事件，避免切頁後重新渲染。
- 修復高像素手機手勢後，瀏覽器抑制相容 click 時無法關閉視窗的情形：關閉鍵對原地觸控放開有可靠處理，排除拖曳；保留原生鍵盤 click，避免重複消耗歷史紀錄並還原入口焦點。

## 驗證

- 畫質策略、弱裝置、大螢幕像素預算與取樣恢復的 3 個單元測試，加上既有測試共 20 檔、140 個通過。
- 高像素手機：實際畫布倍率約 1.749→1→1.749；手勢後關閉正常，無 pageerror。
- 靜止 500ms 觀察到新增 WebGL draw call 為 0。記錄：output/ux-node60-quality-visual.json。
- 手機原生旋轉、雙指縮放；桌面按鍵相機動畫停止後恢復；320 / 390px 標註；盒體白底與厚度；著色器重用；複製、匯出、橫向選單共 10 個回歸測試通過。
- 四倍 CPU 降速、390px、8 層×5 盒、8 層 LED：rAF p95 約 33.4ms（前節點約 66.7ms），桌面約 16.8ms。單次壓力樣本包含工具及主執行緒負載，不代表手機實機 FPS，也不保證所有裝置 60 FPS。
- 高清與操作畫面：output/ux-node60-hd-390.png、output/ux-node60-active-390.png。
- 最終正式建置成功：output/ux-node60-build-final.log；正式版本畫質切換、手機滿版、電腦動畫、材質快取與匯出共 8 個測試通過：output/ux-node60-production.log。正式版靜止倍率約 1.749，操作 1，恢復 1.749，靜止期間新增繪製 0，無 pageerror。
