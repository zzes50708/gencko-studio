# 手機主要內容前的高度修正

本輪依使用者提供六張畫面，將檢查範圍從大標題擴大至導流、搜尋、篩選、說明及操作列。

- 基因圖鑑：工具卡片改成短列入口，手機隱藏卡片的重複說明，保留兩個連結。搜尋移除重複可見標籤，保留 aria-label，輸入字級 16px。
- 飼養指南：導流改為短列，隱藏重複的閱讀索引宣傳標題，保留四個章節切換按鈕，縮短第一章之前的空白。
- 文章列表與內頁：縮短搜尋、分類、主題標籤及返回列間距，日期列緊湊呈現。
- 特寵醫院：縮短收藏提示、搜尋、地區選單、操作與筆數列的間距；保留收藏保存限制說明。
- 計算機：縮短物種區、說明按鈕及章節標題，保留原有基因與 Het 操作及即時計算。
- 守宮介紹、購買流程、FAQ、健康與飼養評估：同樣壓縮手機導流列。評估進度條定位保持原有設定。
- 補正身分證及文章內頁的容器對齊，基因詞條標題置於工具列之前。

驗證：38 個已修改 Vue 檔案編譯成功。19 個相關瀏覽器案例首次為 18 成功、1 個 FAQ 返回搜尋失敗；該案例單獨重跑成功。逐頁手機與桌面截圖存於 output/ux-node40-preamble。沒有部署。
