# 節點 03：種群展示與線上競標 UX 排查

狀態：已依使用者「種群沒必要放大，其他全部修正」完成 A01–A08、B01–B08。B02 採照片下方品系與 ID，不新增放大。選購已售出維持預設關閉，包含重置預設與條件標籤。

## 方法與範圍

瀏覽種群、競標列表及競標詳情，320／390px 原生觸控模擬、768px 觸控平板、1440px 桌面。查看實際公開種群；競標目前無進行中場次，因此另外在本機記憶體注入模擬場次，涵蓋無直購價、長品系、關閉狀態、延長時間、斷線。沒有出價、登入、直購或送出 LINE 訊息，沒有改資料庫。

證據：output/ux-node3-audit.json、output/ux-node3-followup.json；截圖 output/ux-node3-breeders-320.png、output/ux-node3-auction-320.png 等。競標截圖為測試資料。

## 修正與驗證（2026-10-02）

- 種群手機兩欄、平板三欄、桌面四欄；照片下顯示品系及 ID，提供品系／基因／ID 搜尋。圖片失敗顯示重試，沒有放大或額外詳情入口。
- 列表移除重複段落標題與返回按鈕；競標品系兩行、性別獨立、價格緊湊並只顯示有效直購價；縮短倒數，平板改三欄。
- 競標獨立 loading/error/retry。批次且完整分頁讀取出價摘要；詳情同步 store 更新並每 15 秒更新出價及場次資料，背景頁暫停輪詢、重新上線／顯示時更新。
- 出價紀錄失敗保留已讀資料並標示可能過期，不顯示假空紀錄，資料未確認時停用確認出價。缺值不當作 NT$0；場次 status、截止時間一起判斷。
- LINE 直購詢問共用 oaMessage 產生器，保留 ID、價格及場次連結。分享取消無干擾，複製失敗顯示可選取的手動連結。
- 宣傳圖卡使用原生 dialog 與既有歷史管理：背景不可聚焦、鎖定捲動、返回先關閉。
- Vitest：auction-presentation、animal-inquiry、shop-catalog 共 9 項通過。新節點 03 E2E 3 項通過；選購及共用互動回歸 10 項通過；320／390px 全站內容標題回歸 2 項通過，每寬度檢查 19 頁。
- 320／390／768／1440px 兩頁實際排版均無橫向溢出。證據 output/ux-node3-fixed.json 與同名截圖。競標為本機攔截的測試資料，未出價、登入、購買、送出訊息或修改資料庫。觸控驗證為 Chromium 模擬，未宣稱真實 iOS 裝置驗證。

正式驗證：npm run build 成功；競標／種群既有互動契約另有 8 項通過。最新正式建置本機預覽使用 http://localhost:3002 ，尚未部署。

正式建置額外確認：手機公開種群搜尋／物種切換正常，兩頁 HTTP 200、無橫向溢出、無 pageerror。競標以 REST 攔截模擬資料確認摘要、詳情最高價、缺直購價隱藏、分享失敗替代連結、online 事件同步結標狀態，全數通過。正式版不提供 Vue 開發內部資料存取，因此注入 setupState 的 E2E 僅使用開發伺服器；正式版另以網路攔截驗證。
