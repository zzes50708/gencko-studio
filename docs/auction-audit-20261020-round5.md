# 競標與管理持續複驗第五輪（2026-10-20）

## 實際重現與修正

1. 同個體已有待處理得標交易，但庫存狀態被改回可售時，候選搜尋與上架仍放行。改為同時檢查未結束場次，以及待聯絡、待通知、待付款、待核帳的交易；候選清單隱藏，伺服器也拒絕上架。已過結標時間但尚未結算的 active 場次亦保留占用。無人出價、取消、棄標仍須先明確調整庫存，才允許重上架。
2. 上架在等待個體資料鎖前即取得時間，等待結束後可能建立已過期場次。改為取得鎖、整理照片後重新取得真實時間，檢查開結標時間。使用獨立測試個體與兩個資料庫連線重現：一邊持鎖 25 秒，另一邊嘗試建立 1 秒後結標的場次；修正前放行，修正後拒絕。
3. 得標管理 RPC 回傳 null 或不完整物件時呈現空白，容易誤認沒有結算紀錄。新增回應結構檢查，錯誤時顯示重試；合法 outcome:null 仍正常顯示尚未結算。
4. 新增交易占用拒絕文案辨識，明確拒絕後清除該上架請求，管理員可重新選取；未知網路結果仍保留原請求供確認。

## 已驗證

- 14 個單元／API 測試檔、53 項測試通過。
- 原上架資料庫 19 項檢查通過；交易占用 16 項檢查通過；兩份腳本均回滾且確認未殘留測試個體或場次。
- 資料鎖時間測試通過，未殘留測試場次；另行建立的測試個體已核對後刪除。
- 競標安全、即時更新、管理、上架與得標流程共 27 個瀏覽器測試通過（出價安全測試內另涵蓋 19 種情境）。初次啟動曾因隔離測試伺服器未運行而連線失敗，重啟後完整重跑通過。
- 隔離正式建置成功；正式產物的 SSR 六項檢查通過，包括最高價、無出價、查價故障、結標索引與結構化資料安全。
- 照片、個體資訊、手機滑動、圖片失敗與分享資訊另 11 個瀏覽器測試通過。
- 安全顧問未列出競標函式或公開競標資料表的 ERROR／WARN；private 資料表無用戶端政策為刻意禁止直接存取。全站共用資料的既有 RLS 風險仍存在，詳見 auction-shared-data-access-followup.md，不代表全站安全檢查已通過。
