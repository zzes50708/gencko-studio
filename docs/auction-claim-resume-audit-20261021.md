# 領標返回與複製流程排查（2026-10-21）

## 修正

- 單場結標頁從 LINE 返回後沒有補查，無法自動反映已領標、已核帳與已取消。增加 focus、pageshow、online、visibilitychange 恢復查詢；隱藏、離線、忙碌或已有查詢時不重複發起。
- 每次按複製得標訊息都重新產碼，讓先前貼上的碼失效，也可能碰到產碼頻率限制。有效期內重複複製沿用原訊息；剪貼簿失敗後重試亦沿用。
- 背景查詢不應撤下尚未送出的訊息。結果狀態、金額與 claimed_at 未變時保留，確認領標或付款／取消狀態改變時撤下舊碼。
- 背景查詢失敗撤下不再可信的結果與操作，提供重試，避免把舊狀態當最新結果。
- 整合測試抓到會員頁逐張查詢會與父層整批查詢重複且清掉訊息。改由父層一次更新全部得標紀錄，子卡片不額外逐場發請求；會員頁也支援 focus、pageshow 恢復，並略過離線查詢。
- 卸載移除新增監聽；原有 revision 保護仍阻止登出與換帳號後的舊回應回寫。

## 驗證

- 新瀏覽器案例先重現返回網站未補查（查詢次數未增加），再修正。
- 新案例涵蓋有效碼重複複製僅產碼一次、同批恢復事件合併、一般補查保留訊息、領標完成撤碼、付款與取消更新及錯誤狀態。
- 會員頁整合斷言不發逐場 RPC，並確認 focus／pageshow 只產生一次批次查詢。
- 37 項單元／API 通過。
- 最終整合 20 個瀏覽器案例全部通過（44.2 秒），包含會員頁批次查詢與單場返回；先前失敗已重現並修正。
- 最終正式建置通過，SSR 六項隔離驗證通過。
- 本輪未改正式資料庫、未發送 LINE 訊息、未送出真實出價，前端尚未部署。
- 前輪一次性 LINE 驗證的後端已生效；新版前端與 Android 真機流程仍需部署與驗收。
