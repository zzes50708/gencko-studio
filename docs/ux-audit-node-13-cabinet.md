# 節點 13：訂製設備與 3D 模擬排查

2026-10-06 排查手機 390×850、橫向 740×360 與桌面 1440×850；本輪未修改產品來源。

## 集中發現

1. 選擇韓國加熱墊後，3D 匯出文字正確寫韓國加熱墊，但下方需求摘要仍寫標配美國加熱墊，可能送出矛盾需求。
2. 手機複製／匯出回饋寫入 downloadStatus，但唯一顯示區 workspace-footer 為 !touchMode；實際下載成功後手機沒有「已建立文字清單」文字。
3. 手機層數 8 可成功選取並匯出 GENCKO-8層2抽A4盒訂製櫃.txt；沒有觀察到該選項超出畫面。收納高度選單在 740×360 內完整顯示，但按鈕被壓成 20px，觸控容易誤選。
4. 預覽選單觸發與 LED 按鈕高 36px；主要匯出按鈕手機 40px。保留使用者要求緊湊，不宜全面改為大型卡片；可优先改善主要操作與彈窗觸控。
5. 三張案例卡目前沒有任何案例照片或規格，仍占據大區塊；宜保留案例待更新說明，收掉無實際內容的佔位卡。

## 已核對

- 手機與桌面皆有一個 3D canvas，無整頁橫向溢出；這不是原生實機旋轉、雙指縮放或材質效果已驗收的宣告。
- 常用手機選單在直向畫面內完整顯示。收納款式於內高 0 時停用是既有必要限制，測試跳過停用欄位。
- TXT 標題與檔名符合現行配置；加熱墊匯出值正確。下方需求摘要與它是兩段獨立邏輯，需统一欄位来源以免再不同步。
- 未做真實訊息發送、報價、部署或寫入外部應用程式。

## 下一步

一次修正上述不一致與版面問題，再集中驗證複製失敗、下載、連續更新與模型觸控；不新增生成確認流程、不還原手機頂部導覽或視角按鈕。

- 加熱墊需求摘要改讀取即時配置，韓國／美國與 TXT 一致。
- 手機複製與匯出回饋可見，拒絕剪貼簿權限時提供失敗提示；主要操作按鈕提高到 44px。
- 數值選單依可用高度增加欄數，橫向 740×360 的內高選項約 38px，全部完整顯示，沒有選項區捲動。
- 移除三張沒有實際內容的案例佔位卡，保留案例更新說明。
- 三個修改的 Vue 元件編譯檢查通過；cabinet-ux 端到端測試涵蓋配置摘要、實際下載、複製成功與失敗、橫向選單邊界及關閉。
- 本輪未驗證實體手機的旋轉、雙指縮放或材質觀感；保留既有 3D 實作。未部署。
