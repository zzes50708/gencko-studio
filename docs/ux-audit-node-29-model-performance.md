# 節點 29：模型建立運算

## 問題與修正

createCabinetModel 每次建立模型都生成两張 256×512 備援木紋貼圖，即使已載入正式清水模／石紋貼圖或選用純色貼皮，板面不會使用它們。

改為有正式貼圖時使用正式來源；純白／純黑不建立備援木紋；需要紋理而來源尚未載入時才產生既有備援。保留板面 UV、材質參數、光線與幾何。正式來源由工作區持有，模型釋放不銷毀共用來源。

## 量測

Chromium 手機視窗、正式清水模貼圖已載入，直接建立並釋放模型，每個配置三次樣本。

| 配置 | 修正前中位 | 修正後中位 |
| ---- | ---------: | ---------: |
| 4 層 |    33.4 ms |    12.1 ms |
| 8 層 |    26.4 ms |    13.3 ms |

原始資料：output/ux-node29-before.json、output/ux-node29-after.json；量測腳本 output/ux-node29-profile.mjs。樣本數少，開發環境有其他負載，此結果只描述模型建立 CPU 時間，不是整頁載入、GPU 渲染或實機流暢度評分。

兩份原始 JSON 的 canvasReadyMs 是早期腳本將量測工作算入的總時間，不用於初次載入結論。腳本已修正時間記錄位置。初次載入尚未證明改善。
