# 選購頁返回定位與手機介面修正

## 2026-10-01

- 手機卡片收藏／加入比較按鈕移至價格右側，縮小為 24px 高。320px 與 390px 實測價格和按鈕無重疊；桌面翻牌操作維持。
- 手機頁尾只顯示品牌、介紹及社群連結；768px 以下隱藏導覽與版權／標語列，桌面維持。
- 捲動恢復的根因：700ms 定時器會先於非同步頁面完成；即使 `page:finish` 已觸發，Suspense 新頁面仍可能尚未插入 DOM，導致捲動依舊個體頁的高度截斷。
- 移除提前恢復定時器，返回 `/shop` 時以型錄根元素 `data-scroll-page` 與 `data-scroll-ready` 等待真正渲染與載入完成。MutationObserver 完成後解除；過期導航回呼不捲動新的路由。
- Lenis 恢復前重新量測高度。全站載入更多個體只在 `/shop` 觸發。
- 保留篩選收合、只看收藏與瀏覽紀錄狀態；返回時不因 beginner query 自動開啟手機篩選對話框。
- 瀏覽器返回深層列表：離開 10714px／100筆，返回 10714px／100筆。
- 個體頁返回按鈕：離開 8456px／100筆，返回 8456px／100筆。
- 桌面篩選收合返回仍為收合，頁尾導覽仍可見。

- 固定進度列及進度條寬度 100%，從螢幕左邊延伸至右邊。
- 層級由 1011 降為 900，低於桌面與手機導覽；保留導覽下方位置與隱藏導覽時的位移。
