# 節點 05：新手入門與購買流程

2026-10-05；使用者授權「繼續修正」，本節點七項問題已修正並完成瀏覽器驗證。未部署。

證據：output/ux-node5-audit.json 與 start-here / buying-guide 的320、390、768、1440px截圖。正式建置 localhost:3000，手機使用 Chromium 觸控模擬，沒有送出訊息、登入或交易。

## 問題與建議

1. 新手頁重複的入口分布在知識地圖、準備清單與底部三條路徑，320px正文1788px。建議手機地圖改緊湊雙欄或標題＋一行摘要，底部保留真正下一步，不再重複 care / health / faq。
2. 頁內索引 LEARNING MAP / THREE PATHS / CHECK 對繁體中文新手不直觀，且視覺順序是地圖→三路徑→檢查，實際正文順序地圖→檢查→三路徑。建議中文標籤並與實際順序一致。
3. 主要「評估準備」路徑導向健康評估，飼養前自我評估只在前方地圖；建議明確區分飼主準備與個體健康，主要第二步提供 /qs。
4. 購買流程寫「私訊官方」但該步沒有官方聯絡入口，需從 Footer 找 LINE。建議在私訊步驟補既有官方詢問連結，使用者自行送出。
5. 要求私訊前了解購買規定，卻只導向全分類 FAQ，正文未直接提供付款／保留／訂金等定位。建議明確購買 FAQ 入口或摘要，沿用既有規則，不自行新增交易條件。
6. 新手頁寫靜養2–3天，購買頁寫3–5天；這是跨頁文案不一致。應核對工作室既有標準或明確說明不同情境，不能為了視覺調整自行選定飼養天數。
7. 購買頁手機的決策入口到流程首步仍占較多高度；重複品牌／FAQ／飼養／選購四入口可縮為緊湊入口，流程內文字及連結保留44px觸控高度。

## 已確認正常

- 兩頁四種寬度沒有整頁橫向溢出，手機主標題24px。
- 新手推薦入口可到 /shop?beginner=true，沒有錯誤路由。
- 購買流程既有 inline 操作高度44px；新手頁英文頁內索引38px，可在不加大整區留白的前提改善觸控。
- 不把資訊重複、層級安排這些建議當成按鈕失效或跑版。

## 修正與驗證

- 手機知識地圖改為雙欄；底部路徑收斂為自我評估與挑選個體，桌面同步改為兩欄，移除重複飼養／健康／FAQ 操作。
- 頁內索引改為「了解飼養／到家準備／下一步」，順序符合正文，手機觸控高度至少44px。
- 飼養前自我評估提供主要入口；動物健康與飼主準備的用途明確分開。
- 私訊步驟新增既有官方 LINE，另開分頁；沒有自動傳送訊息。
- 購買規定與決策入口直達 /faq?category=purchase；FAQ 驗證參數後選中購買分類，無效參數保留預設分類，交易條款未修改。
- 兩頁統一到家安置文案，適應與餵食依個體交接說明，不自行選定新天數。
- 購買決策區使用緊湊雙欄44px操作，並移除標題列原有76px最小高度。
