# 節點 23：圖卡非同步生命週期

## 重現

用延遲圖片載入模擬，連續呼叫個體圖卡生成後切至文章頁，再觸發圖片失敗。修正前啟動兩次圖片工作，且新頁收到兩次舊頁警告。

## 修正

個體與競標詳情的生成函式檢查生成鎖，忽略重複呼叫。圖片完成或失敗時檢查路由，切頁後不再畫圖、開啟彈窗或顯示舊頁警告。共用歷史彈窗亦拒絕在所屬路由之外開啟，避免非同步回應污染新頁歷史。

## 驗證

新增回歸測試由失敗改為通過：圖片工作只啟動一次，切頁後警告為零。與既有個體／比較／種群／競標互動測試合計 8 項通過；兩個修改頁面的 Vue 腳本與模板編譯通過。

未部署、未正式建置。圖片下載本身未取消，此次防護處理的是重複工作與過期回應；原本分享失敗的手動連結及圖卡返回關閉測試仍通過。
