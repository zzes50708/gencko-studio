# 特寵醫院立體縣市地圖

## 已實作範圍

`/hospital` 使用單一 TresJS Canvas，呈現台灣 22 縣市的真實邊界、深藍線框量體、橘色選取縣市與粉色收藏縣市標記。地圖按鈕、縣界點選及原有縣市下拉選單共用 `hospCity`，切換縣市會清除行政區條件。院所資訊、收藏及外部導航維持原有流程。

桌機版第一列左側是標題、右側是完整篩選工具；第二列是滿寬 3D 地圖；第三列是滿寬醫院名單。手機依序呈現標題、篩選、同一套 3D 地圖與名單。

地圖同時顯示縣市院所數與已有經緯度的院所光點。2026-09-21 讀取資料為 78 間、其中 11 筆有座標，尚未全數完成定位；既有座標仍發現搬遷問題，詳見同日 checkpoint。沒有生成或猜測缺失座標。線框量體與高度為視覺示意，不代表真實建物、道路、地形或院所數量；放大時隱藏示意量體。離島沿用來源圖資的組合投影位置。

## 互動與效能

- 桌機左鍵與手機單指拖曳平移；右鍵或 Shift 拖曳旋轉；手機雙指捏合縮放。加減與重設按鈕具 44px 觸控範圍。
- 圖內滾輪直接縮放，圖外滾輪捲頁。Canvas 可聚焦，方向鍵旋轉、加減鍵縮放、0 重設。
- 清單可定位院所並捲至地圖，光點可選取院所並返回資料。Google 地圖按需嵌入同一區域，以選中院所名稱及地址查找；切回 3D 保留視角。這不是 Google 圖磚與 TresJS 疊圖，亦不代表 Google 已替缺失資料補回資料庫座標。
- 事件只更新相機目標值；渲染時採 `1 - exp(-12 × delta)` 阻尼，支援減少動態效果偏好。
- 桌機 DPR 上限 1.5、手機 1.25；互動渲染上限分別為 60、30 FPS。這是負載上限，不是未經實機量測的效能保證。
- 使用 `render-mode="on-demand"`，並在相機收斂後明確停止 TresJS RAF。視窗外或分頁隱藏時停止，重新進入及控制事件會喚醒。
- 縣市地面合併、縣界線段合併、街廓採 InstancedMesh、街廓邊線合併；不使用即時陰影、Bloom 或背景持續動畫。
- 程式化 geometry/material/instance 資源、事件監聽器、IntersectionObserver 與 render hooks 在卸載時釋放。
- 手機不因螢幕尺寸而退回靜態地圖；WebGL 初始化失敗或 context loss 才顯示可重試的備援。縣市按鈕及原有醫院名單仍可操作。

## 圖資

- 來源：[Taiwan Atlas](https://github.com/dkaoster/taiwan-atlas)，套件版本 `2021.9.20`，`counties-mercator-10t.json`。
- 原始邊界由內政部圖資轉製；來源套件 MIT 授權附於 `assets/maps/LICENSE-taiwan-atlas.txt`。
- 本地簡化資料約 58 KB；共用弧線只簡化一次，保留相鄰邊界一致性。網站執行時不需要外部圖磚或 API key。
- 更新圖資：`node scripts/build-hospital-map.mjs`。腳本只下載固定版本公開資料，輸出縣界及來源授權。

`.map-stage` 的 `data-map-frames`、`data-map-idle`、`data-map-calls`、`data-map-triangles` 可供瀏覽器驗證靜止時不持續渲染與 draw calls。手機真機溫度、記憶體壓力及長時間操作仍須以實機量測，不能用桌面模擬取代。
