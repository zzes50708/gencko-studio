# 節點 22：非同步更新與切頁

競標列表的更新先等待場次資料，再讀取摘要。原本只在元件卸載時取消摘要；路由轉場期間舊元件仍存在，因此離開頁面後完成的資料更新會啟動新的摘要請求。

修正：路由離開時立即標記停止並取消摘要；資料更新返回後檢查停止狀態，不再延續舊頁請求。同一頁已有更新時忽略重複更新。

驗證：使用延遲資料更新，先切到文章頁，再放行舊請求。原本摘要請求數由 1 增至 2，修正後維持 1。新回歸測試與種群／競標既有測試共 4 項通過，競標 Vue 腳本與模板編譯通過。未部署、未正式建置。

另外檢查會員競標紀錄的 requestId 與卸載失效處理、全站資料載入的共用 Promise／載入鎖，已有防護，未為此改動。
