## 修改

- 手機篩選的四個基因分類收起時以兩欄呈現，展開後使用整列。維持原生 details／summary 與 44px 點按範圍。

- 文章縮短章節標題、段落、引文、章節選單及作者區間距。保留完整正文、原有正文 16px 字級及引用連結。
