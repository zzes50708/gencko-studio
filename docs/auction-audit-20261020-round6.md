# 競標與管理持續複驗第六輪（2026-10-20）

## 本輪實際修正

1. 上架搜尋將 null 當作空清單；非陣列或壞資料也未驗證。現在區分搜尋失敗與合法空結果，檢查個體 ID 與品系欄位，失敗可重新搜尋，不會同時顯示「找不到可上架個體」。保留管理員先前明確選取的個體。
2. 候選搜尋的伺服器上限是 30 隻，但畫面沒有說明。滿額時提示目前顯示前 30 隻，應輸入更完整的 ID 或品系；沒有宣稱庫存只有這 30 隻。
3. 公開個體注意事項吃掉管理員輸入的換行。以純文字 span 保留分行，並讓長字串可換行；仍使用 Vue 文字插值，沒有改用 HTML 注入。320px 手機寬度驗證無水平溢出。
4. LINE 聯絡綁定輪詢直接讀取裝置 Date.now，裝置日期快兩天時會立即撤下仍有效的綁定碼。改用全站已校準的 auctionNow，日期正常、快兩天與慢兩天皆可建立訊息並完成驗證；舊延遲回應不能覆蓋新成功狀態。

以上搜尋異常、換行與裝置日期案例均先重現失敗，再修改程式並重跑通過。未建立真實出價、傳送 LINE 訊息或修改既有資料。
