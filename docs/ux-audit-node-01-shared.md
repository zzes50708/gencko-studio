# 使用者體驗分析：節點 01，全站共用介面

日期：2026-10-02。分析基準為本機工作區；已加回但尚未部署的爬櫃標題區塊包含於此基準。僅建立分析文件與證據截图，未修改網站程式。本節點尚未經使用者驗收；未開始節點 02。

## 排查範圍與方式

- 全站頂部／底部導覽、選單分類、目前位置、會員、主題切換與關閉行為。
- 共用容器、五種寬度的導覽边界、留白、字級、亮色／深色模式。
- 共用彈窗的焦點、Esc、關閉後焦點還原、背景互動、返回行為與捲動鎖定。
- 頂部閱讀進度、手機底部安全空間、收藏詢問浮動按鈕與導覽彈窗層級。
- 圖片預覽提示、上下滑動關閉與原生觸控事件。
- 共用選單動畫取樣與減少動畫偏好。

寬度：320、390、768、1024、1440px；主要高度 844px。使用本機 Chrome／Playwright，觸控手勢透過 Chromium 原生 Input.dispatchTouchEvent 驗證。共用圖片預覽、文章閱讀狀態與收藏狀態另透過既有 store API 注入，以隔離共用元件；這些測試不是實際文章詳情或購買流程驗收。平板結果包含點按範圍測量，未代表實體平板速度。

## 已確認正常

- 五種寬度的導覽項目均沒有超出螢幕左右邊界。
- 320px 手機底部每項約 64×61px，390px 為 78×61px，點按範圍足夠。
- 手機分類清單項目約 170×48px（390px），知識選單完整顯示於畫面內。
- 主題切換可在更多選單操作，亮暗狀態會改變；未發現共用選單文字消失。
- Esc 關閉手機導覽後，焦點返回「知識」入口。
- 減少動畫偏好下，選單 transitionDuration 約 0.00001s，已有降級。
- 收藏詢問浮動按鈕 z-index=9999，導覽 sheet 位於其上；按鈕中心的 elementFromPoint 為選單項目，沒有穿透至詢問按鈕。
- 注入收藏狀態後，在飼養評估、健康檢查、飼養指南與會員頁底部，未發現浮動詢問按鈕與主內容可操作元素交疊。此為底部位置抽測，不等同所有捲動位置皆已驗證。
- 共用選單開關期間，45 個 requestAnimationFrame 取樣：中位 16.7ms、P95 18.7ms、最大 19.8ms。僅表示此次本機瀏覽器取樣未有明顯延遲；不能推論實體手機 FPS、電量或全站效能。
