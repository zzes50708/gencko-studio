# 競標上架預設與顯示複驗（2026-10-20）

## 新上架設定

- 餌料預填「冷凍蟋蟀/杜比亞」，可依個體特殊狀況修改。
- 餵食頻率改為選單：「1-2天/次」「3-4天/次」「一週一次」；預設第一項。
- 運送不再提供輸入欄，新上架固定帶入「黑貓 +180 元；三重面交免運」。
- 管理表單與公開詳情統一使用「個體注意事項」。
- 起標價預填 200 元，金額上下調整步長為 100；最低增額預設 100。
- 預設預約開標：依台灣日曆計算下週一 10:00 開標、同週六 22:00 結標，兩個時間仍可手動修改。週一當天也採下一週，不取當天；週日跨入台灣週一及跨年有固定日期測試。
- 立即開標仍可選；壓線延長規則不變。
- 既有場次與待確認上架請求不改寫；重試沿用原內容，避免新預設破壞既有回執確認。

## 額外查核與修正

- 公開詳情原本未顯示已保存的餵食頻率，已補齊；配送欄位改標示「運送／面交」。
- 頻率選單補上明確的無障礙名稱，避免選項文字混入標籤，影響輔助科技及操作定位。
- 管理場次列表收到 null／不完整回應時，改為讀取失敗；只有真正空陣列才顯示沒有場次，避免把服務故障當成無資料。

## 驗證

- 7 個相關單元／API 測試檔、30 項通過，包含台灣星期與跨年日期、原上架暫存恢復及金額契約。
- 25 項競標／管理瀏覽器回歸通過，涵蓋新預設、實際 ArrowUp／ArrowDown 每次 100、頻率選取與請求內容、固定運送內容、立即／預約開標及回執遺失恢復。
- 公開詳情新增的飼養／運送／注意事項顯示案例通過。
- 已檢視上架表單截圖；既有 320／390／1440 像素寬度檢查通過。
- 隔離正式建置通過，程序結束碼 0，紀錄為 `output/auction-listing-defaults-build.log`；差異格式檢查通過。
