## 確認正常與驗證界線

- 兩頁四種寬度皆無整頁橫向溢出；手機標題24px、1440px兩頁標題同為36.8px。
- 介紹圖片載入成功；手機介紹比較沒有橫向捲動，但順序仍可改善。
- 飼養指南各章節入口有作用，FAQ正常前往問答頁；繁殖相關文章可實際前往 /articles/ART-011。
- 飼養指南正文320px6114px、390px5816px。篇幅長本身不是bug，不用直接刪除必要飼養資訊來追求短頁。
- 本節點不判定或修改醫療／飼養數值；原生讀屏、實體手機效能及內嵌環境3D的完整手勢驗收尚未執行，不冒充已完成。

- 01、05：手機照護決策入口雙欄、短章節入口四欄；導覽13.12px，介紹入口44px高。
