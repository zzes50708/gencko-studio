# 節點 63：開放式盒口與塑膠平面外緣

- 移除壓克力盒整片上蓋及蓋子專用材質，移除保留盒型跨過開口的橫條；九種資料盒型均保持頂部開放。停用的盒型仍保留資料，未重新加入客戶選單。
- 全部塑膠盒新增連續四邊圓角平面外緣，包含上面、底面、內側、外側的實體厚度，中央沒有封口面。
- 外緣包含在原有盒體外尺寸內；盒壁上緣向內退到外緣內側，保留向內收的盒壁與底框。照片沒有外緣精確尺寸，外緣寬約 0.6cm／厚 0.18cm 為模型估值，未將估值改成商品規格。
- 同配置所有抽屜共用同一份外緣幾何，維持各自抽拉及選取；通風細節位置同步往內調整，避免浮在縮入後的盒壁外。
- 瀏覽器測試检查九種盒型的開口中央是否被頂部三角形遮蔽、塑膠外緣外尺寸、朝上法線。另檢查盒底白色與板厚、跨層數著色器重用。
