# Gencko Studio 競品與標竿網站優勢分析

研究日期：2026-08-28  
基準網站：[Gencko Studio](https://www.genckobreeding.com/home)

## 研究範圍與判讀方式

本次逐一檢查 14 個參考網站的公開首頁、商品/個體頁、分類頁、知識頁、購買與聯絡資訊。網站部分內容由 JavaScript、會員狀態或後台資料即時載入，因此「本次爬蟲沒有看到」不等於「網站一定沒有」。Gencko 的功能判讀另外對照目前本機 Nuxt/Vue 程式碼。

### Shop 誤判更正

先前搜尋引擎文字快照曾顯示 `/shop` 空列表與最高價格 0，但這不是實際商店狀態。2026-08-28 以 Playwright 與 Codex for Chrome 兩種真實 JavaScript 瀏覽器重新驗證後，豹紋守宮分頁顯示 20 筆商品、最高價格 12000；肥尾守宮分頁顯示 7 筆商品、最高價格 7000，空狀態皆不可見。

原因是商店 UI 使用 `store.inv`，而 `store.loadDataFromAPI()` 於 `app.vue` 的 `onMounted` 後才從 Supabase 載入資料；`pages/shop/index.vue` 的 SSR `useAsyncData` 結果目前主要供 JSON-LD schema 使用，沒有直接作為商品 UI 的首屏資料。未完整執行 hydration 或沒有等待客端請求的文字爬蟲會先讀到空 store 所渲染的空狀態。這是爬蟲/SSR 可見性差異，不是庫存、Supabase 或一般使用者 UI 故障；若要改善，應列為獨立 SSR/SEO 技術變更，不能當成一般 UI 缺陷處理。

### 任務範圍更新

使用者後續已授權適度調整內容與功能，包含合併頁面及調整導覽內容。因此競品建議可進一步轉化為資訊架構、文案、導航、內部連結與小型 UI 功能；但不得捏造評價、保固、血統、健康、餵食或商業數據。涉及 Supabase schema、外部 API、付款/登入、基因演算法、商業規則與 Hero Lab 核心 3D/scroll 邏輯時，仍須先回報風險。

## 二、各頁面優勢內容深度萃取

### 1. 首頁

**最值得吸收：**

- Feipien 用成立故事、實體空間與物種探索建立品牌情緒；Entobuzz 則把場域特色、創辦人專業、課程與預約 CTA 串成完整服務路徑。
- Gray Matter 在首頁直接說明專長物種、健康穩定血統、國際經驗與證明卡，讓訪客快速理解「為什麼是這間繁殖者」。
- Gencko `/home` 已有品牌、社群、快速導覽、熱門精選與最新文章。靜態文字爬蟲曾顯示熱門商品為空，但 Codex for Chrome 實際執行 hydration 後確認熱門精選正常顯示，空狀態不可見；因此不能把靜態快照當成首頁缺少商品。首頁真正可改善的是品牌、可售個體、工具與內容入口的視覺主次。[Gencko 首頁](https://www.genckobreeding.com/home)

**建議首頁資訊順序：**品牌承諾 → 目前可售個體 → 繁育/健康證據 → 新手入口 → 基因與醫院工具 → 知識文章 → 購買 CTA。Hero Lab `/` 與一般首頁 `/home` 應保持清楚分工，避免訪客誤以為進入的是展示實驗場而非可購買平台。

### 2. 選購頁與個體頁

**最值得吸收：**

- Rex/Pashou 將學名、外觀、難度、溫濕度、空間、餵食、適合族群、來源與售後放在同一商品頁，讓商品頁同時完成教育與轉化。
- Snakelove 公開價格、性別、預訂狀態、出貨前餵食紀錄和隨機出貨限制；UU 把運費、到貨風險、開箱錄影和詢問方式放在購買流程附近。
- Gencko `/shop` 已有物種、狀態、價格、性別、年份、基因、搜尋、收藏、歷史、手機篩選與最多三隻比較，功能基礎不弱；商品頁也已公開 ID、基因/品系、生日、健康、基因正確、運輸賠償與購買規則。[Gencko 商店](https://www.genckobreeding.com/shop) · [Gencko 個體頁](https://www.genckobreeding.com/product/S-56081)

**主要落差：**不是商品缺失，也不是再增加更多篩選，而是讓既有資料更容易掃讀：圖片、品系、價格、狀態、性別、生日、照片日期、收藏與比較需要有穩定且一致的視覺層級。爬蟲空狀態屬 SSR/客端資料可見性差異；若未來要改善，應另開 Shop SSR/SEO 技術變更，不要混入一般卡片與 IA 重構。

### 3. 種群展示與繁育檔案

**最值得吸收：**

- Yunung 以豹紋、肥尾與品系文章累積長尾搜尋，並用傷口、腳趾卡皮、眼睛、鈣缺乏、排便等檢查項目教新手挑選個體。
- Guisu 讓物種、個體名稱、性別、編號、價格與狀態可被分類頁索引；Gray 則把血統穩定、來源與個體證明卡明確化。

**Gencko 可形成的差異化：**把 `/breeders` 從圖片展示升級成「種群檔案」：個體 ID、性別、出生年份、血統來源、已知基因、繁育角色、配對紀錄、後代連結與目前狀態。這是一般電商較難複製的專業資產。

### 4. 基因工具與基因知識

**最值得吸收：**

- Gray 的基因清單按顯性、隱性、多基因分類，並搭配圖片；其計算機明確分成 sire/dam，提供警示與結果說明。[Gray Matter 基因清單](https://graymatterreptile.com/pages/gene-list) · [Gray Matter 基因計算機](https://graymatterreptile.com/pages/gene-calculator)
- Gencko 的基因獨立頁已具備基因簡介、詳細敘述、資料來源，以及對 Zero、Pastel、Lemon Frost 等不確定性或健康風險的警語，內容誠信度是優勢。[Gencko 基因頁：Zero](https://www.genckobreeding.com/genes/%E9%9B%B6) · [Gencko 基因頁：Lemon Frost](https://www.genckobreeding.com/genes/%E6%AA%B8%E6%AA%AC%E9%9C%9C)

**主要落差：**Gencko 應把「遺傳模式、可視表現、健康/倫理警示、可搭配基因、計算機入口」做成同一套可視化結構；計算結果還應有「如何解讀、哪些不是保證、相關基因頁」的下一步，而不只顯示百分比。

### 5. 知識文章與 SEO

**最值得吸收：**

- Gray 以 husbandry、breeding、misc 分類，內容標題直接對應新手問題，例如第一隻蛇怎麼選、餵食數量與頻率。
- Yunung 以品系、飼養、日常與爬蟲知識建立大量長尾頁；Entobuzz 則將知識轉為課程、參觀與預約，讓內容有明確商業下一步。
- Gencko 文章已能以科學文獻、資料來源與免責聲明支撐專業度；例如混養文章有文獻與「一體一缸」結論。[Gencko 文章範例](https://www.genckobreeding.com/articles/ART-008)

**建議架構：**以物種為第一層、以新手/飼養/健康/繁殖/基因為第二層；文章底部固定出現相關品系、相關個體、計算機、醫院和購買流程。每篇文章補「適合誰、閱讀時間、更新日期、資料來源」會比單純增加文章數更有效。

### 6. 購買須知、FAQ 與聯絡

**最值得吸收：**

- THEORCS 的配送/保固政策具體，包含運輸方式、天候、到貨與活體保障；Pacman 的付款、配送、退貨、會員、訂單與客服資訊完整；UU/Snakelove 把開箱錄影、餵食與風險限制明確寫出。
- Pashou 將商品、教育與用品整合；Entobuzz 則公開地址、電話、場域、資格與預約 CTA，商業真實感很強。
- Gencko 已有 `/buying-guide` 的挑選 → 詢問 → 確認 → 到家流程、三個檢查點與 `/why-gencko` 的資料透明/飼養教學/工具/醫院四項信任主張；個體頁也有 48 小時、開箱錄影、運輸死亡/斷尾處理與退款條件。[Gencko 購買流程](../pages/buying-guide.vue) · [Gencko 信任頁](../pages/why-gencko.vue)

**主要落差：**Gencko 規則本身不弱，但相關內容分散於商品頁、`/buying-guide`、`/why-gencko`、`/faq` 與 Footer。可以把既有事實重寫成一致的購買時間線、信任摘要與跨頁導流，也可調整導覽與頁面整併；新增保固、退款或運輸承諾仍需有既有政策依據。[Gencko Footer](../components/TheFooter.vue)

## 三、立即落地優化建議：Top 5

### P0：重整資訊架構、導航與 Hub
