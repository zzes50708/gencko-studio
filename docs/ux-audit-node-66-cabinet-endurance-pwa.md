# 節點 66：爬櫃外觀、長時間操作與更新可靠性

本輪為本機修正，尚未部署。保留既有手機確認尺寸後生成模型的流程。

## 修正與驗證

| 項目         | 結果                                                                                                                                                               |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 壓克力外觀   | 保留四面有厚度的透明板、通風孔與白底，將邊條對齊板材，避免底邊突出。實際瀏覽器截圖檢查抽出後的側面與開放頂部。                                                     |
| 實物校準     | 板厚、孔徑、孔距、塑膠盒外緣與底部內縮集中於 physicalProfiles.ts，材質厚度與幾何共用。數值仍是照片估值，等待實物量測。                                             |
| 手機相容性   | Chromium 觸控流程及 WebKit 引擎流程通過。Windows WebKit 不能替代 iPhone Safari 或 Android 實機驗收。                                                               |
| 大量壓克力   | 幾何原型最多保留四種，場景使用獨立副本並正常釋放。本次 40 盒幾何建構首次 26.7ms，後續 6.5–9.4ms；這不是整頁載入時間或手機 FPS。                                    |
| 長時間穩定性 | 修正每次生成重建 LTC 光源查表貼圖的洩漏。10 輪、30 次配置切換後 GPU 資源數保持穩定，未出現頁面錯誤；尚不代表數小時實機溫升測試。                                   |
| PWA 更新     | 修正離線頁預快取路徑造成 Service Worker 無法啟用。線上正常取頁，離線顯示備援頁，恢復連線重試原頁。更新後尺寸設定由同分頁 sessionStorage 恢復，手機不自行生成模型。 |

## 證據

- 最終隔離正式建置成功：output/ux-node66-build-final.log。
- 單元測試 20 檔、141 項通過。
- 最終形狀、開放頂部、設定恢復、10 輪資源測試均通過。
- 正式建置 PWA 線上／離線／重試測試通過。
- Service Worker 兩版本切換測試：自動重載、保留 6 層設定、無頁面錯誤。此測試更換 worker 版本，並非兩個正式線上發行版本。
- 先前本輪 WebKit 五項流程測試及正式建置八項流程測試通過。
- 大量模型旋轉量測有波動，未宣稱所有手機固定 FPS。實機測試與實物尺寸仍待補充。

## 範圍

本輪修改模型、材質共用尺寸、設定恢復及全站 PWA 導航／更新流程。沒有改動其他頁面版面或正式部署。
