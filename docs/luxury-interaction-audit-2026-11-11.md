# Gencko 感官互動審查與核心重構

## 審查範圍與設計判斷

2026 年 11 月 11 日盤點 32 個頁面模板與 66 個 Vue 元件，檢查入口、互動樣式、動態媒體條件及共用元件引用。實際走訪 26 個靜態路由的初始畫面，另對首頁、選購、個體詳情、工具及基因圖鑑進行重點觀察。登入、刊登、競標與所有工具結果狀態仍需各自的情境驗證。

本輪採用 Gencko 現有橘紅、暖白／深色、宋體標題、細線與真實守宮照片。主動選擇三處核心重構，讓照片具有可拿取的紙張層次，並讓身份資料、品系與行動入口具有明確主次。

EK 首頁可見雙物種焦點、暖色留白、浮動導覽與錯角動物卡片。這輪取材於照片卡的前後層次及入口回饋。參考站的再次連線曾逾時，觀察以第一次成功載入的實際畫面為準。[EK Reptiles](https://www.ek-reptiles.com/)

## 已交付程式

### 首頁照片框

- pages/home.vue 的照片與標示包入 home-hero**print，照片裁切由內層 home-hero**photo 負責。
- assets/css/home-experience.css 控制雙層照片紙、回正、照片縮放、方向箭頭及媒體條件。
- 外層連結保持固定命中區，內層照片紙位移。

### 選購卡片

- components/ShopFlipCard.vue 提供個體連結、收藏、比較、完整資料與圖片錯誤處理。
- 翻面沿用 rotateY、前後面與 backface-visibility 結構。使用 CSS linear() 取樣阻尼曲線，提供一般 easing 作為相容處理。
- 卡片材質樣式集中回元件，移除 pages/shop/index.vue 重複覆寫。

### 個體詳情

- pages/product/[id].vue 加入照片裱框、低彩度基因與保障標示、桌機資訊底板與行動箭頭。
- 320px 檢查發現相似個體推薦的日期受到卡片雙層內距擠壓，已縮減窄螢幕內距。

## 互動條件

新增加的懸停位移與回正效果只在至少 768px、精確游標、支援 hover 且允許動態的裝置啟用。手機及觸控使用平面照片框。減少動態偏好會即時停用回正、縮放及箭頭位移。

本輪以 CSS 過渡與既有 Vue 結構實作。所有行動箭頭皆標記 aria-hidden，原本連結的可讀名稱仍可直接使用。

## 來源

實作前已讀取專案 Design Rule，並查閱 Inspira UI Flip Card 與 Interactive Hover Button 官方原始結構。翻面使用既有相同核心結構，照片紙層次採本專案已有的紙卡語彙。[Design Rule](https://github.com/zzes50708/gencko-studio/issues/5)、[Flip Card 原始碼](https://inspira-ui.com/r/flip-card.json)、[Interactive Hover Button 原始碼](https://inspira-ui.com/r/interactive-hover-button.json)

## 開發頁面樣式錯誤恢復

使用者回報計算機的 style index=7 由 PostCSS 解析到 TAXON_LEOPARD_GECKO。檢查目前 calculator.vue 的 SFC 結構解析成功，樣式索引為 0～6。實際使用中的 Chrome 首頁仍顯示舊樣式請求留下的錯誤遮罩。

已重新載入該分頁，再透過首頁入口進入 localhost:3000/calculator，確認雙親設定與配對結果區正常顯示。另對使用者的 3000 連接埠執行計算機互動回歸，涵蓋即時結果、頁內說明及反向匹配。

## 第三輪基因工具

本輪自主選定基因圖鑑的閱讀入口與計算機的選擇回饋。

- 圖鑑詞條改為左側名稱、右側閱讀提示與圓形方向箭頭。懸停與鍵盤聚焦時，箭頭填色並以短距離位移回應。1099px 以下以名稱與方向箭頭構成入口，長名稱可自然換行。
- 手機的方向箭頭預設顯示。桌機位移須同時滿足精確游標、hover 與允許動態，減少動態設定會停止過渡。
- 計算機的物種選單箭頭反映開合，親代角色與基因分類提供 aria-pressed 狀態。結果以低濃度紙面色區分機率欄，移除舊的裝飾折角。
- 清除親代卡片早期樣式中的無條件 hover 位移，並實測觸控選取後卡片維持原位。
- 7 項相關瀏覽器案例通過，涵蓋即時結果、頁內說明、反向匹配、Het 切換，以及圖鑑的類型／搜尋交叉篩選。
- 另實測 1440px 鍵盤聚焦、減少動態、雙 Het 配對的即時 25%／75% 結果與物種選單定位，並檢查 320px、390px、768px 的觸控畫面及詞條內部邊界。截圖位於 output/luxury-tools/。

## 第四輪長文閱讀與競標展示

本輪自主選定文章詳情的章節定位與競標列表卡片。

- 文章章節列在閱讀正文時持續可用。章節跳轉依據選單的實際高度及頂部位置留出空間，標題可落在選單下方。
- 手機驗證發現外層 cont 的 overflow-x:hidden 建立了捲動容器，導致章節列無法依視窗吸附。文章具有章節列時，外層改用 overflow-x:clip，閱讀器也使用 clip 裁切。
- 競標照片加入裱框與獨立裁切視窗。桌機懸停／鍵盤聚焦時，圖片小幅放大，品系名稱與查看場次入口同步回應。
- 預告場次的狀態標籤加入實底，改善淺色照片上的辨識。窄手機的查看場次維持單行，金額可依欄寬自然換行。
- 12 項章節情境驗證通過，涵蓋 375px、430px、1440px、1920px 的長標題邊界、重複選章、正文重建與標題焦點。1920px 的一項案例曾遇到開發頁面換頁中斷，單獨重跑後通過。
- 另有一項競標列表至詳情的狀態回歸通過。以隔離測試資料檢查進行中與預告場次，驗證縮放、減少動態、價格、計時器和入口。
- 實際檢查 1440px、320px、390px、768px 的文章及競標畫面，章節列在畫面內且不遮住跳轉標題。截圖位於 output/luxury-reading/，競標截圖採隔離測試資料。
- 最終型別檢查通過。另以 320px、390px、1440px 驗證六位數金額完整顯示、預告標籤實底，以及窄手機入口單行。

## 第五輪底部章節按鈕與會員卡片

依使用者指定，文章章節改為固定在底部的按鈕，並進一步要求按鈕位於版面內。

- 章節按鈕在版面寬度內自動換行，長名稱最多顯示兩行。章節數量較多時，章節列內可垂直捲動。
- 章節列排在手機主導覽及正文進度線上方，頁尾預留對應空間。按鈕至少 44px 高，支援鍵盤焦點及重複點選同一章。
- 沿用 ChapterTrail 的 IntersectionObserver 方式追蹤閱讀章節，並在元件卸載時清理觀察器。章節跳轉從目前正文重新取得標題，支援 v-html 重建後的內容。
- 同時改善會員收藏與瀏覽紀錄卡片的照片裱框、長名稱及方向箭頭。個體連結與收藏按鈕為獨立控制，收藏按鈕提供選中狀態，操作可直接更新本機收藏。
- 18 項相關瀏覽器案例通過，涵蓋章節版面邊界、標題焦點、重複跳轉、短文章、文章入口與收藏取消。型別檢查通過。
- 桌機及手機畫面位於 output/luxury-reading/article-buttons-\*.png 與 output/luxury-member/。會員卡片截圖使用隔離測試資料。
- 最終另實測 320px、390px、1440px 的章節按鈕與收藏／瀏覽紀錄操作，並以 320×568px、60 個長章節名稱確認按鈕與頁面皆無橫向溢出。

## 第六輪答案開合與競標相簿

- FAQ 原本僅淡入文字，答案高度突然出現。改為 240ms 的網格高度展開與收合，保留文字的輕量淡入。實測發現舊全站 active 樣式覆蓋轉場起點，已提高本頁轉場選擇器的優先順序。
- 競標詳情的桌機數字按鈕改為附編號的照片縮圖，選中時顯示橘色框線與編號底色。圖片經既有代理取得 160px 版本，載入失敗時保留編號按鈕。
