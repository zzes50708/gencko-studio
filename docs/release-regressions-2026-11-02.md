# 上輪發布回歸修復

範圍：修復上一輪引入的首頁閃字、額外按鈕、文章圖片失效，以及文章／基因詳情分欄；不修改資料庫文章與交易規則。

## 根因與修正

- 首頁：可見 ClientOnly 備援介紹在水合前短暫出現。移除可見備援與新增選購按鈕，保留隱藏的品牌語意及原本「首頁」入口。首頁按鈕使用主按鈕樣式，避免日間 ghost 規則造成黑字。
- 圖片：URLSearchParams 將檔名中的 `%20` 重編碼為 `+`。實測同一公開照片，`+` 版本回傳 404 JSON，`%20` 版本回傳 200 WebP。候選網址現在只改變寬度，保留原始編碼；文章圖片的候選失敗時回退原始尺寸。
- 文章／圖鑑：reading.css 的 column-width 是兩欄來源，已撤回並固定單欄，不再套用報刊式分欄。
- 資料庫：唯讀核對 12 篇已公開文章；雖然內容含 HTML 與 style，但沒有分欄或固定像素限寬設定。資料庫沒有改寫。
- 文章圖片：移除對未知圖片強加 3:2 比例的處理，保留真實尺寸及自然比例；HTML 安全白名單仍保留。

## 回歸驗證範圍

- 圖片檔名含空白、逗號的候選網址編碼。
- 未執行 JavaScript 時的首頁外觀、單一首頁按鈕及文字對比。
- 與資料庫相同的 HTML 包裝結構，在 390／1440／1920px 的單欄與滿版寬度。
- 無圖基因詳情在相同三種寬度的排版。
- 圖片候選回傳 404 時可回退，不會永久隱藏照片。
- 實際文章清單的全數圖片載入，並重跑上輪的登入接續、證書、儲存拒絕與主要頁面驗收。
